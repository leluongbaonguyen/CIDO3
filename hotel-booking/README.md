# Hotel Booking System

Project fullstack gồm:
- backend Node.js + Express + MySQL
- frontend React + JSX + Vite

## Chạy backend
cd backend
npm install
cp .env.example .env
# tạo database và chạy file src/sql/schema.sql rồi src/sql/seed.sql
npm run dev

## Chạy frontend
cd frontend
npm install
npm run dev
